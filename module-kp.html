Модуль подготовки коммерческих предложений (КП)

Извлечение спецификаций, сопоставление с расценками и черновик КП на локальном GPU — с детерминированным расчётом и контролем инженера.

1. Локальное исполнение на GPU (ключевой принцип)

Система разворачивается в инфраструктуре заказчика и выполняет обработку документов, сопоставление спецификаций и генерацию черновиков КП на локальном GPU.

Подход:

  • Языковая модель используется для понимания документов и классификации.
  • Все числовые расчёты выполняются детерминированно.
  • Цены берутся только из справочников, прайсов и проверенных источников.
  • Никакие данные не отправляются во внешние публичные модели без явного разрешения заказчика.

Почему это важно

Преимущества для заказчика

  • Защита коммерчески чувствительной информации.
  • Соответствие требованиям 152-ФЗ.
  • Возможность работы даже при недоступности внешних сервисов.
  • Предсказуемая производительность и стоимость.

2. Назначение модуля

Автоматизация механической части подготовки КП:

  • Извлечение спецификаций из PDF/DOCX/XLSX.
  • Сопоставление с базой расценок.
  • Получение цен поставщиков.
  • Расчёт сметы.
  • Формирование черновика КП и сопроводительных документов.

Финальная ответственность за КП остаётся за инженером.

3. Что входит в поставку

  • Импорт и распознавание PDF, DOCX, XLSX, JPG, PNG.
  • OCR для сканированных документов на русском языке.
  • Извлечение спецификаций из таблиц.
  • Сопоставление позиций с базой расценок.
  • Работа с прайс-листами поставщиков.
  • Детерминированный расчёт сметы.
  • Генерация DOCX и PDF по шаблонам заказчика.
  • Контрольный список готовности КП.
  • Версионирование документов и аудит изменений.

4. Архитектура решения

Компонент Назначение
Document Ingestion Загрузка и классификация документов
OCR Engine Распознавание сканов
Local LLM Extractor Извлечение структурированных данных
Matching Engine Сопоставление с базой расценок
Pricing Service Работа с прайсами поставщиков
Calculation Engine Детерминированный расчёт сметы
Document Generator Формирование КП и PDF
Bitrix24 Integration Связь со сделкой и хранение артефактов

Рекомендуемый стек: Python + LangGraph + PostgreSQL + локальная LLM + OCR.

5. Ключевые ограничения и гарантии качества

Система не имеет права:

  • Генерировать цены, объёмы или коэффициенты.
  • Использовать цену без указания источника.
  • Финализировать КП без проверки инженером.
  • Отправлять КП клиенту автоматически.

Система обязана:

  • Хранить источник каждой цены.
  • Показывать трассировку расчётов.
  • Подсвечивать аномальные позиции.
  • Вести полный журнал изменений.

6. Целевые показатели

Показатель Цель
Подготовка черновика КП до 5 минут
Точность извлечения спецификаций ≥90%
Полнота извлечения строк ≥95%
Снижение чел-часов инженера на 50% и более
Календарный срок подготовки КП 1–2 рабочих дня

7. Этапы внедрения

  1. Обследование и нормализация базы расценок.
  2. Пилот на 10–15 сделках.
  3. Подключение поставщиков и автоматизации запросов цен.
  4. Масштабирование на все типы КП.
  5. Калибровка качества и аналитика.
